# Demo JPA Hibernate

Projeto demonstrativo de mapeamento objeto-relacional com Spring Boot, JPA e Hibernate.

## 💡 Sobre o projeto

Desenvolvido como projeto de estudo do curso Java e Orientação a Objetos. A aplicação demonstra o uso do Spring Data JPA com Hibernate como provedor de persistência, mostrando como mapear entidades Java para tabelas de banco de dados e realizar operações CRUD.

## 🛠️ Tecnologias

- Java 25
- Spring Boot 4.1.0
- Spring Data JPA / Hibernate
- H2 Database (testes)
- Maven

## 📐 Conceitos aplicados

- Mapeamento objeto-relacional (ORM)
- Anotações JPA (`@Entity`, `@Table`, `@Id`, etc.)
- Operações CRUD com Spring Data JPA
- Relacionamentos entre entidades
- Banco em memória H2 para testes

## ▶️ Como rodar

1. Clone o repositório
```bash
git clone https://github.com/EllianLima/demo-jpa-hibernate
```
2. Abra o projeto na sua IDE de preferência
3. Configure o banco de dados no `application.properties`
4. Execute a classe principal
